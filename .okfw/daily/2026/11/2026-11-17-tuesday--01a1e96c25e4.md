## Notes

- **Changed:** Phase 0 bootstrap. The repo, the build files, the lint scripts, the wiki, ADR-0001 to ADR-0004 and ISSUE-001 to ISSUE-007 exist.
- **Learned:** tree-sitter-zig v1.1.2 uses ABI 14. The other four grammars use ABI 15. ztree supports both layouts.
- **Changed:** Phase 1. `third_party/` holds the pinned sources. `src/abi.zig` mirrors the ABI, and the tests compare it with C and with the reference runtime.
- **Learned:** The lex mode width changes from 4 to 6 bytes in ABI 15. State entries with `lex_state` 0xffff hold non-terminal extras only.
- **Changed:** Phase 2. `src/lexer.zig` ports the reference lexer. A differential test compares it with the reference lexer in each lex state.
- **Learned:** Zig 0.17 has no `**` operator for arrays. Use `@splat`. No vendored scanner calls `get_column`, so the test calls it directly.
- **Changed:** Phases 3 and 4. The parser and the recovery code match the reference runtime on 436 inputs. ADR-0005 records the arena design.
- **Learned:** The reference runtime recovers from errors on valid input, so phase 3 needs the recovery code. No input reaches the switch from a keyword to the word token.
- **Next:** Phase 5. Build the tree API, the cursor and comment extraction.
