## Notes

- **Changed:** The Zig caches are on the external drive. `~/.bashrc` sets `ZIG_GLOBAL_CACHE_DIR` and `ZIG_LOCAL_CACHE_DIR` when the drive is mounted. The old caches on the internal disk are gone.
- **Changed:** Phase 14. The GLR stack holds 256 heads ([ADR-0013](/decisions/adr-0013-a-bound-of-256-glr-stack-heads--01a1f2f0124a.md)). [ISSUE-016](/issues/issue-016-the-glr-stack-limit-of-64-heads--01a1f080f76c.md) is closed.
- **Learned:** On 73,701 files, the largest head count is 90. Only C++ headers that the C grammar reads need more than 64. An extra token, such as a comment, makes the pop paths of a reduce finish in different rounds, so the pop adds more versions.
- **Learned:** Tables of more than 65,535 items make `repeat_depth` overflow, and a safe build panics ([ISSUE-017](/issues/issue-017-an-overflow-of-repeat-depth-on-large-repetitions--01a1f2f04d37.md)).
- **Next:** Phase 15, the overflow of `repeat_depth` (ISSUE-017).
- **Changed:** Phase 15. `Subtree` has no `repeat_depth` ([ADR-0014](/decisions/adr-0014-no-repeat-depth-in-a-subtree--01a1f309a44d.md)). A table of 70,000 items in each grammar parses as in the reference. [ISSUE-017](/issues/issue-017-an-overflow-of-repeat-depth-on-large-repetitions--01a1f2f04d37.md) is closed.
- **Learned:** The sibling functions of the reference TSNode API scan the siblings. The full flat-tree check of a table of 70,000 items took more than 10 minutes, so the table test uses `checkWide`.
- **Next:** All phases of PLAN.md are done. [ISSUE-009](/issues/issue-009-rare-zig-forms-that-the-patched-grammar-cannot-read--01a1ec8ab913.md) is the only open issue.
