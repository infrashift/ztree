## Notes

- **Changed:** ADR-0007 and ADR-0008. ztree becomes the Tree-sitter service of semscope. PLAN.md has phases 8 to 13 and ISSUE-010 to ISSUE-015.
- **Learned:** semscope uses about a dozen node methods, one cursor and queries with `#eq?`, `#any-of?` and `#match?`. Users write the queries, so the full query language is part of the contract.
- **Changed:** Phase 8. tree-sitter-cpp v0.23.4 is the sixth grammar. 599 corpus examples pass. 149 libc++ files match the reference runtime. The C ABI version is 2.
- **Learned:** tree-sitter-cpp v0.23.4 uses ABI 14 and has an external scanner for raw strings. lexis needs no change for the new ABI version.
- **Next:** Phase 9, the flat tree and the node API (ISSUE-011).
- **Changed:** Phase 9. `src/flat.zig` writes the flat tree. The C ABI is version 3, with `ztree_parse`, field overrides and six language functions. The Go binding has `Parser`, `Tree`, `Node` and `TreeCursor`.
- **Learned:** The cursor field id does not give `ts_node_child_by_field_id`. An ERROR node has no field map, and an inherited field can name a grandchild. [ADR-0009](/decisions/adr-0009-field-overrides-and-the-node-rules-of-the-flat-tree--01a1f080b1ed.md) adds field overrides for these lookups.
- **Learned:** `ts_node_next_sibling` skips an empty sibling at the end of a node. `ts_node_has_error` is true for an ERROR leaf with no error cost.
- **Learned:** 903 outside files match the reference node by node. One libstdc++ header needs more than 64 stack heads ([ISSUE-016](/issues/issue-016-the-glr-stack-limit-of-64-heads--01a1f080f76c.md)).
- **Next:** Phase 10, the bounded regex engine (ISSUE-012).
- **Changed:** Phase 10. `src/regex.zig` reads an ASCII subset of RE2 and matches with a Pike VM ([ADR-0010](/decisions/adr-0010-a-pike-vm-for-an-re2-subset--01a1f0902c3e.md)). The C ABI is version 4, with `ztree_regex_match`.
- **Learned:** `regexp.Match` of Go is a search, and `$` without the flag `m` matches only at the end of the text. For ASCII, the flag `i` adds two Unicode folds: K (U+212A) and ſ (U+017F).
- **Next:** Phase 11, the query compiler (ISSUE-013).
- **Changed:** Phase 11. `src/query.zig`, `query_analysis.zig`, `query_predicates.zig` and `query_blob.zig` compile a query into a blob ([ADR-0011](/decisions/adr-0011-a-structural-port-of-the-reference-query-compiler--01a1f0a8133a.md)). The C ABI is version 5, with `ztree_query_compile`.
- **Learned:** The cursor splits a state at a fallible step, and the parse-table analysis decides which steps are fallible. So the match count depends on the analysis, and the port keeps it.
- **Learned:** The reference fails an assertion or passes a null pointer to `strncmp` on two rare inputs. The test skips the reference for them.
- **Next:** Phase 12, query execution (ISSUE-014).
- **Changed:** Phase 12. `src/query_exec.zig` ports the reference query cursor over the flat tree ([ADR-0012](/decisions/adr-0012-a-port-of-the-reference-query-cursor-over-the-flat-tree--01a1f111feba.md)). The C ABI is version 6, with `ztree_query_exec`. The Go binding has `NewQuery` and `QueryCursor`.
- **Learned:** The query cursor reads `ts_tree_cursor_current_status`, which the flat tree did not keep. Each node now has `status_field_id` and the flag `ZTREE_NODE_LATER_FIELD`.
- **Learned:** `start_depth` is a `uint16_t` in the reference. It wraps for an empty match of `[...]*`, and the port keeps the wrap.
- **Learned:** The `any-` predicates of go-tree-sitter pass when no node of the capture is a hit.
- **Learned:** Each `-Dquery-dirs` or `-Ddiff-dirs` value builds new debug binaries. The Zig cache filled the disk once. Clear `.zig-cache` after many such runs.
- **Next:** Phase 13, the handoff to semscope (ISSUE-015).
- **Changed:** Phase 13. The [migration guide](/guides/migrate-semscope-from-go-tree-sitter-to-ztree--01a1f122b34b.md) and a Go benchmark are in place. The local semscope branch `ztree-runtime` passes its tests, its parity step and its `zmake check` with ztree.
- **Learned:** semscope gives the same scan output with both runtimes on nine source trees. Files with syntax errors can differ, because go-tree-sitter v0.25.0 holds an older runtime than the reference v0.27.2.
- **Learned:** `Parser.Parse` sized each node buffer from the largest earlier parse. The fix cuts the bytes that a parse allocates by a factor of 11.
- **Learned:** The default parity corpus of semscope needs go-tree-sitter in `go.mod`. With ztree, set `SEMSCOPE_PARITY_GO_CORPUS`.
- **Next:** All phases of PLAN.md are done. [ISSUE-016](/issues/issue-016-the-glr-stack-limit-of-64-heads--01a1f080f76c.md) is the open work.
